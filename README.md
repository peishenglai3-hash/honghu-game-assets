# 红色源代码：洪湖篇 · 美术资产归档

> **项目状态：** 已完成章节资产归档。该仓库集中保存序章及第 1–4 章的地图、角色、场景和交付包。

![洪湖暮色像素场景](README-cover.png)

## 内容

- 序章与第 1–4 章的美术目录
- 场景地图分层、碰撞与交付清单
- 已整理的角色、环境图像及少量压缩交付包

原目录名尽可能保留，便于与游戏工程中的资源路径对应。该仓库不包含游戏源码、私人人机交互档案或本地参考素材库。README 封面为单独生成的归档插画，不属于游戏关卡资源。

历史素材路径可能保留早期场景命名（例如“涂家大院”）；文件夹名用于资源定位，不自动构成剧情正典。剧情事实应以 [游戏仓库](https://github.com/peishenglai3-hash/honghu-chronicles) 中明确标记的现行章节内容为准，例如“杜家大院”。

仓库包含多个章节的 PNG/JPG、地图数据、说明文档和压缩交付包。大型二进制资源通过 Git LFS 管理；首次克隆后请安装 Git LFS 并运行 `git lfs pull` 获取完整文件。
