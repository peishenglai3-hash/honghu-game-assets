# MAP_CH3_TU_COMPOUND｜涂家大院外围及院内

## 交付范围

- 地图 ID：`MAP_CH3_TU_COMPOUND`
- 场景称谓：美术资产清单称“涂家大院”，详细剧情文档称“杜家大院”；本交付统一使用资产清单地图 ID。
- 画布：1664×936 px
- Tile 基准：48×48 px 或其倍数
- 镜头：俯视三分之四、正交式可操作地图
- 人物：守卫、攻门队、伤员、清点人群均由运行时生成，不烘焙在地图图层。

## 固定空间与不可漂移地标

1. 左下前门土路与矮墙树影隐蔽区。
2. 左下成熟大树：七个状态必须保留同一位置、树干、树冠体量和低墙遮挡关系；火光只能改变受光，不能让树消失或变成裸根。
3. 下方高院墙与中部铁皮双门。
4. 左上宴饮/团丁生活区。
5. 右上封闭式湖北传统榨房。
6. 中央大院内侧及通往后院的路径。
7. 右侧武器与财物集中区。
8. 左侧伤员休息区。
9. 上方后院/街面方向的视觉出口。

门外撞门木柱为无绳整木，无金属头、轮架或攻城器械结构。榨房内部悬吊撞杆的绳索属于木榨工艺结构，与撞门木柱无关。

## 状态表

| 状态 ID | 视觉与玩法差异 |
|---|---|
| `STATE_WAITING` | 正门开启；隐蔽等待；院内宴饮；榨房完整无火。 |
| `STATE_GATE_CLOSED` | 正门关闭并落闩；门楼、屋檐和瓦片完整。 |
| `STATE_FIRE_STARTED` | 封闭榨房猛烈起火；火舌经气窗、门缝与檐口外窜；浓烟映墙；正门仍闭。 |
| `STATE_GATE_ATTACK` | 无绳整木撞击门板中心；门板受力但未破；门楼屋檐和瓦面完全不受损。 |
| `STATE_GATE_BROKEN` | 门闩与门叶失效，中央形成通道；仅门板/五金/门槛有碎屑；屋顶、瓦片、门柱完整。 |
| `STATE_AFTER_BATTLE` | 右侧武器与财物分区集中；左侧伤员区可见；火势减弱；中央留空用于清点。 |
| `STATE_DEPARTURE` | 武器和包裹捆扎待运；伤员区收拢；榨房余烬；前门路线清空。 |

## 榨房实现

榨房采用“实体封闭、游戏镜头剖切”的处理：土砖木构围护、院内双扇木门、高位气窗和完整瓦顶均真实存在；内部设备通过把屋顶/檐口归入 `L06_OCCLUSION_HIGH` 来显示或隐藏。

核心设备固定为：横置巨型整木榨床、竖排草圈油饼、木楔、屋架绳索悬吊撞杆、接油槽与陶缸、石碾、蒸/炒料灶、草圈和油料筐。禁止还原成长梁跷杆、大型开放水槽或现代机械榨油机。
